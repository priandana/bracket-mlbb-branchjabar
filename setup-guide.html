📖 Panduan Setup Firebase

Ikuti langkah-langkah berikut untuk menghubungkan web ini dengan Firebase.

Langkah 1
Buat Project Firebase

Buka console.firebase.google.com dan login dengan akun Google kamu.

Klik tombol "Add project" → isi nama project (contoh: ml-bracket) → klik Continue → (opsional) aktifkan Google Analytics → klik "Create project".

Langkah 2
Aktifkan Realtime Database

Di sidebar kiri Firebase Console, klik Build → Realtime Database.

Klik "Create database" → pilih lokasi server (pilih asia-southeast1 untuk Indonesia) → pilih "Start in test mode" → klik Enable.

⚠️ "Test mode" membuat database terbuka untuk baca/tulis selama 30 hari. Ini cukup untuk keperluan turnamen. Setelah turnamen selesai, ubah rules-nya.
Langkah 3
Daftarkan Web App

Di Project Overview, klik ikon </> (Web) untuk menambahkan web app.

Isi nama app (contoh: ML Bracket Web) → klik "Register app".

Firebase akan menampilkan firebaseConfig — salin seluruh object tersebut.

Langkah 4
Paste Config ke firebase-config.js

Buka file js/firebase-config.js di folder project ini, lalu ganti bagian firebaseConfig dengan config yang kamu dapat dari Firebase:

const firebaseConfig = {
  apiKey:            "AIzaSy...",
  authDomain:        "ml-bracket.firebaseapp.com",
  databaseURL:       "https://ml-bracket-default-rtdb.asia-southeast1.firebasedatabase.app",
  projectId:         "ml-bracket",
  storageBucket:     "ml-bracket.appspot.com",
  messagingSenderId: "123456789",
  appId:             "1:123456789:web:abcdef..."
};
⚠️ Pastikan databaseURL diisi dengan benar! Cek di Firebase Console → Realtime Database → URL di bagian atas halaman.
Langkah 5
Jalankan via HTTP Server (Wajib!)

Web ini TIDAK bisa dibuka langsung dari file (protokol file://) karena Firebase memerlukan HTTP. Gunakan salah satu cara berikut:

Opsi A — npx serve (termudah, perlu Node.js):

cd "d:/Bracket Mobile Legend"
npx serve .

Kemudian buka http://localhost:3000 di browser.

Opsi B — VS Code Live Server:
Install extension "Live Server" di VS Code → klik kanan index.html → Open with Live Server.

Opsi C — Host di internet (gratis):
Upload ke GitHub Pages, Netlify, atau Vercel agar bisa diakses semua orang via link.

Langkah 6
Login & Setup Turnamen

Buka admin.html di browser → masuk dengan password default: admin123

Di tab Setup Turnamen:

1. Isi nama turnamen
2. Atur jumlah tim (slider)
3. Isi nama tiap tim
4. Klik "Simpan Pengaturan"
5. Klik "Generate Bracket"

Bracket akan otomatis muncul di index.html secara real-time!

💡 Ganti password default segera di tab Pengaturan → Ganti Password.
Langkah 7
Bagikan Link ke Penonton

Bagikan URL index.html (atau link hosting) ke seluruh peserta dan penonton. Mereka akan melihat bracket update secara real-time tanpa perlu refresh!

Admin bisa input skor di admin.html kapan saja.
